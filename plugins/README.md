# Plugins

Plugin ecosystem for extending the Conversation Platform.

## Available Plugins

- `demo-generator/` — Interactive demo generation
- `meeting-booking/` — Calendar meeting booking
- `lead-scoring/` — Lead scoring and qualification
- `crm/` — CRM integration (HubSpot, Salesforce)
- `calendar/` — Calendar integration (Google, Outlook)
- `email/` — Email campaign management
- `proposal/` — Proposal generation
- `custom/` — Custom plugin templates
