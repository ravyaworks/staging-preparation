# Documentation

Documentation hub for the Conversation Platform. This directory contains all project documentation organized by domain.

## Structure

- `architecture/` — System architecture and design decisions
- `product/` — Product requirements and specifications
- `database/` — Database schema and data models
- `api/` — API documentation
- `ai/` — AI/ML integration documentation
- `conversation/` — Conversation engine documentation
- `knowledge/` — Knowledge base documentation
- `channels/` — Channel integration documentation
- `dashboard/` — Dashboard and UI documentation
- `deployment/` — Deployment guides
- `security/` — Security policies and practices
- `testing/` — Testing strategies and guides
- `workflows/` — Workflow engine documentation
- `decisions/` — Architecture Decision Records (ADRs)
- `diagrams/` — System diagrams and visualizations
- `standards/` — Coding standards and conventions
- `templates/` — Documentation templates
