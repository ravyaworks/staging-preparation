# Knowledge

Knowledge base components for RAG (Retrieval-Augmented Generation).

## Components

- `templates/` — Knowledge base templates
- `parsers/` — Document parsers (PDF, DOCX, HTML, etc.)
- `loaders/` — Data loaders for various sources
- `chunkers/` — Text chunking strategies
- `embeddings/` — Embedding generation
- `vector-store/` — Vector database management
- `retrievers/` — Retrieval strategies (semantic, hybrid, etc.)
- `indexing/` — Index management and maintenance
