# Channels

Communication channel integrations for the Conversation Platform.

## Supported Channels

- `website/` — Embeddable web chat widget
- `whatsapp/` — WhatsApp Business API
- `instagram/` — Instagram Messenger
- `messenger/` — Facebook Messenger
- `telegram/` — Telegram Bot API
- `email/` — Email integration (SendGrid, SES, SMTP)
- `sms/` — SMS integration (Twilio, Vonage)
- `slack/` — Slack API
- `discord/` — Discord Bot API
- `teams/` — Microsoft Teams
- `api/` — Custom API integration
- `custom/` — Bring your own channel
