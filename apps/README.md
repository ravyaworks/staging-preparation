# Apps

Application entry points for the Conversation Platform.

## Applications

- `api/` — Core REST and WebSocket API server
- `dashboard/` — Admin and tenant dashboard (Next.js)
- `website-widget/` — Embeddable chat widget for websites
- `admin-console/` — Internal admin console for platform management
- `documentation/` — Developer documentation site
- `playground/` — API and integration testing playground
