# SDK

Client SDKs for integrating with the Conversation Platform.

## Available SDKs

- `javascript/` — JavaScript/TypeScript SDK
- `react/` — React library and hooks
- `nextjs/` — Next.js integration
- `flutter/` — Flutter/Dart SDK
- `android/` — Android (Kotlin) SDK
- `ios/` — iOS (Swift) SDK
- `node/` — Node.js server SDK
