# Services

Independent microservices for the Conversation Platform.

## Services

- `gateway/` — API gateway and reverse proxy
- `auth-service/` — Authentication and authorization
- `conversation-service/` — Conversation management
- `ai-service/` — AI provider orchestration
- `knowledge-service/` — Knowledge base operations
- `workflow-service/` — Workflow execution
- `channel-service/` — Channel message routing
- `notification-service/` — Push/email/SMS notifications
- `analytics-service/` — Analytics and reporting
- `file-service/` — File upload and storage
- `search-service/` — Full-text and vector search
- `scheduler-service/` — Scheduled tasks and jobs
- `webhook-service/` — Outgoing webhook delivery
- `integration-service/` — Third-party integrations
