# Security Policy

## Reporting a Vulnerability

We take the security of the Conversation Platform seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to security@conversation-platform.dev.

## Scope

- Authentication and authorization mechanisms
- Data encryption and storage
- API security
- Multi-tenant isolation
- Channel integrations

## Response

We will acknowledge receipt of your report within 48 hours and provide a detailed response within 5 business days.
