# Providers

Third-party service provider integrations.

## Categories

- `ai/` — AI model providers (OpenAI, Anthropic, Gemini, DeepSeek, Mistral, Ollama, OpenRouter)
- `embeddings/` — Embedding model providers
- `vector-db/` — Vector database providers (Pinecone, Weaviate, Qdrant, etc.)
- `storage/` — File storage providers (S3, GCS, Azure Blob)
- `email/` — Email service providers
- `sms/` — SMS service providers
- `notifications/` — Push notification providers
