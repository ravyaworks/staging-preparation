# Infrastructure

Infrastructure as code and deployment configuration.

## Structure

- `docker/` — Docker Compose files and container configuration
- `kubernetes/` — Kubernetes manifests and Helm charts
- `terraform/` — Terraform infrastructure definitions
- `nginx/` — Nginx configuration
- `monitoring/` — Monitoring stack (Prometheus, Grafana)
- `logging/` — Logging stack (Loki, Elasticsearch)
- `backups/` — Backup strategies and scripts
- `ssl/` — SSL/TLS certificate management
- `scripts/` — Infrastructure management scripts
